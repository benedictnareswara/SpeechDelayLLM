# Dependencies for the Orange Pi Zero 3 (aarch64 / Python 3.10).
#
# ⚠️ THE DIRECT PINS ARE STILL UNVERIFIED on the board. Resolving them is
# Milestone 0. The *transitive* pins below are not optional — see the note.
#
# Known risks to check on-device:
#   * onnxruntime — aarch64 manylinux wheels exist but lag x86 releases;
#     the version that actually installs on py3.10/aarch64 may differ.
#   * ctranslate2 (via faster-whisper) — some builds cap numpy<2. If pip
#     backtracks forever, pin numpy first and let ctranslate2 follow.
#   * soxr — has aarch64 wheels; falls back to a slow source build if not.
#
# Once `pip install -r` succeeds and tools/bench_device.py runs, freeze the
# WHOLE resolved set over this file, transitive packages included:
#     /opt/speechllm/.venv/bin/pip freeze > deploy/orangepi/requirements-device.txt
# Do not freeze only the direct packages. The two failures that cost a day of
# bring-up (rapidfuzz, PyYAML) were both transitive and both invisible to a
# `pip freeze | grep` of the direct names.

numpy>=1.24,<2.0
onnxruntime>=1.16
faster-whisper>=1.0.0
sounddevice>=0.4.7
soxr>=0.3.7
pyserial>=3.5

huggingface-hub>=0.21,<1.0
PyYAML>=6.0,<7
